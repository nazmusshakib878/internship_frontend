# Primeor Solutions - Frontend

Modern, high-performance React + TypeScript + Vite + Tailwind CSS frontend interface matching the Figma design specifications.

## 🌟 Features
- **Navbar**: Responsive with smooth anchor scrolling and mobile menu
- **Hero Section**: Dynamic headline, code preview card, live stats, and backdrop gradients
- **About Section**: Core internship benefits and value highlights
- **Curriculum & Programs**: 3-level progressive internship breakdown with action triggers
- **Services Section**: Clean grid of tech capabilities with hover effects and Unsplash imagery
- **Interactive Section**: Live component demos (Contact Form, Color Switcher, Greeting Generator, Calculator)
- **Project Gallery**: Auto-sliding slideshow with thumbnails, pause/play, and full-screen lightbox
- **Contact & Footer**: Application submission form wired to the backend API

## 🚀 Getting Started

### 1. Install Dependencies
```bash
cd frontend
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
The output will be placed in the `dist/` directory.
